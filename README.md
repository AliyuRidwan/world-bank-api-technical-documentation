# World Bank API Technical Documentation & Data Analysis

## Project Overview

This project demonstrates how to access, interpret, document, and analyze publicly available economic data using the **World Bank Indicators API**.

It focuses on retrieving economic indicators such as GDP per capita and population data for selected African countries, working with JSON responses, and transforming raw API data into meaningful insights.

The project combines technical writing, API documentation, data analysis, and business analysis skills.

## Project Objectives

- Explain how the World Bank Indicators API works.
- Demonstrate how to retrieve public datasets using API requests.
- Understand and interpret JSON-formatted API responses.
- Analyze economic trends across selected African countries.
- Communicate findings through clear documentation and data summaries.

## Tools & Technologies

- **Python:** Data retrieval and analysis.
- **REST API:** Accessing World Bank economic indicators.
- **JSON:** Structuring and interpreting API responses.
- **CSV:** Organizing extracted datasets.
- **Markdown:** Creating technical documentation.

## Key Features

1. **API Documentation:** Step-by-step guidance on accessing and using the World Bank API.
2. **JSON Explanation:** Examples explaining API response structures and data fields.
3. **Data Analysis:** Examination of GDP per capita and population trends.
4. **Python Script:** Automated data retrieval and analysis.
5. **Troubleshooting Guide:** Common API errors and suggested solutions.

## Economic Indicators

| Indicator | World Bank Code |
|---|---|
| GDP per capita (current US$) | NY.GDP.PCAP.CD |

## How to Run the Project

1. Clone this repository.
2. Install the required dependencies using:

   `pip install -r requirements.txt`

3. Run the analysis script:

   `python scripts/analyze_world_bank_data.py`

4. Review the generated CSV file and analysis summary.
